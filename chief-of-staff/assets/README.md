# Assets

- `icon.svg` is the plugin icon, traced from `mark-source.png`.
- `mark-source.png` is the source art for that trace. **It is synthetic**:
  generated from a text prompt (an abstract mark of one circle joined to two
  smaller ones, a one-root two-leaf tree), not a photograph and not a capture of
  any screen. It carries no generation metadata, because an embedded `tEXt`
  chunk is a payload a reader does not expect and a scanner cannot vouch for.
- `glyphs/` holds the drawn interface glyphs. Same rule: drawn, never captured.

**No screenshot belongs in this repository.** Captures of a running panel
carry live board text, worker names and project paths. If a document needs to
show a surface, draw it or describe it.
